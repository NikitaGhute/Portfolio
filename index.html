Project 01

Timely Task Manager


01. Project Purpose :

I developed this application to practise JavaScript through a real-world task management use case. The goal was to create an interface where users can organize daily tasks, manage priorities, and track their completion status.


02. Key features :
  1. - Add, edit and delete tasks
  2. - Mark tasks as completed.
  3. - Identify important tasks.
  4. - Filter tasks by Inbox, Today, Upcoming, Important and Completed.
  5. - Save task information using browser localStorage.

03.Technologies Used :
Technology Purpose
HTML5 Structure of the application.
CSS3 Styling and layout.
JavaScript ES6+ Application functionality.
LocalStorage Persisting tasks in the browser.
